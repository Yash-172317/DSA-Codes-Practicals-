# Data Structures and Algorithms (DSA) Practicals in C++

This repository contains my **Data Structures and Algorithms (DSA) practical programs implemented in C++**. It includes basic searching and sorting algorithms, stack and queue implementations, linked lists, graph traversal, postfix expression evaluation, and complex number operations using classes and operator overloading.

The repository is created for learning, practicing, and revising fundamental DSA concepts as part of my engineering coursework.

## 📚 Practicals Included

| No. | Program | Description |
|---:|---|---|
| 1 | Linear Search | Searches for an element sequentially in an array. |
| 2 | Binary Search | Searches for an element in a sorted array using the divide-and-conquer approach. |
| 3 | Bubble Sort | Sorts array elements in ascending order. |
| 4 | Stack Using Array | Implements stack operations using an array. |
| 5 | Stack Using Linked List | Implements stack operations using a linked list. |
| 6 | Queue Using Array | Implements queue operations using an array. |
| 7 | Queue Using Linked List | Implements queue operations using a linked list. |
| 8 | Singly Linked List | Demonstrates insertion, deletion, and display operations. |
| 9 | Doubly Linked List | Demonstrates forward and backward traversal, insertion, and deletion. |
| 10 | Graph DFS | Implements Depth First Search traversal using an adjacency matrix. |
| 11 | Postfix Expression Evaluation | Evaluates a postfix expression using a stack. |
| 12 | Complex Number | Demonstrates complex number representation using a C++ class and constructors. |
| 13 | Complex Number Operator Overloading | Demonstrates addition, subtraction, and multiplication using operator overloading. |

## 💻 How to Run the Programs

1. Clone or download this repository.
2. Open the project folder in your code editor.
3. Open a terminal in the folder containing the program.
4. Compile the required C++ file using the following command:

```bash
g++ filename.cpp -o output
```

5. Run the compiled program.

**Windows:**
```bash
.\output.exe
```

**Linux/macOS:**
```bash
./output
```

Replace `filename.cpp` with the actual source filename and `output` with your preferred executable name.
